# Godly Pipes

Godly Pipes is a QoL mod for Factorio.
Whenever you craft or place a pipe by hand, the mod plays a random sound clip of Evil saying **“pipe.”**
The probability of each sound clip can be adjusted through the in-game mod settings.

## Installation

1. Download `godly_pipes_0.1.0.zip` from the latest release.
2. Place the ZIP directly into your Factorio mods folder:
